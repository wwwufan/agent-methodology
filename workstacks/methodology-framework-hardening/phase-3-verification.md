## 边界场景人工静态走查

以下为按规范逐步推演，不是实际多轮 Agent 运行，也不是新增自动化测试。

| 场景及输入 | 规则推演结果 | 核对位置 |
| --- | --- | --- |
| 首次评审 PASS，retry=0 | 无纠正轮次；按原 PASS 门禁收尾 | role-contract §3；single-phase PASS 推进规则 |
| 每轮都有有效进展，连续经历实现修复、重设计、补取证 | 各 FAIL 后启动下一轮分别计 1、2、3；不同路线不豁免，不按角色调用加次数 | role-contract §3 纠正轮次与恢复 |
| retry=3 已启动，纠正后 Reviewer PASS | 不在角色调用前截断；评审通过后正常核对证据及收尾 | role-contract §3 末轮边界 |
| retry=3 本轮 Reviewer 仍 FAIL | 不启动第 4 轮；按原记录/立项规则保存阻塞与恢复条件 | role-contract §3 路由 5 |
| FAIL 后本轮包含探索、返回 Designer、Executor 和 Reviewer | 该轮总计一次 retry；实验次数单独累计；外层不重复计数 | role-contract §3；exploration-loop 单阶段接线 |
| 受控 FAIL 要改快照，尚未获批准 | 停止并请求计划变更，不预扣未启动轮次，不用剩余额度替代批准 | guided-goal-orchestrator 循环与覆盖表 |
| 同一问题预算 3 次、已用 2 次，换窗口/假设/帧 | 仍仅余 1 次；最后一次产生充分证据可交接，否则预算耗尽停止，不另开预算 | budget-and-progress 预算跟随知识问题 |
| 同一问题两个完整实验均无有效进展，仍有预算 | 第二次后暂停，不要求跑满预算；外层引用这两个实验不能再多加一次无进展 | budget-and-progress 有效进展与停止 |
| 实验排除一个有效候选根因 | 可以算有效进展，连续无进展重新从 0 累积；已用实验和阶段 retry 不清零 | budget-and-progress 什么算有效进展 |
| 暂停后用户批准有新策略的有限续试 | 保存历史与恢复起点，只执行获批次数；仍无进展则按续试边界再次停止 | budget-and-progress 停止与恢复 |
| 旧 retry 历史不清、探索消耗缺失 | 先定向查证，不假定 0 或剩余额度充足；无法恢复则明确确认继续额度 | role-contract §3；budget-and-progress 恢复条款 |
| 无栈执行、普通 FAIL 简报、外层复用 | 无栈也记录预算及停止条件；简报包含失败/未知/额度/下一步；不新建栈或重写失败报告 | 输出约定、失败解释、有栈/无栈接线 |
| 正常 pop、恢复、查询和受控审批 | pop 摘要保留四类信息；恢复/查询仍展示树；受控阶段版本、绑定与批准指令不省略 | output-contract；guided 恢复与输出 |

走查补齐了三处边界：末轮不能被上限提前取消；预算用尽不妨碍整理已有充分证据；
有限续试保留历史，不让“已暂停”永久阻断获批的新尝试，也不允许无限清零续试。
